# contracts — Reglas de comunicación

Esta carpeta define cómo se hablan las partes del sistema.

## Qué incluye

- **http/:** Esquemas de los mensajes que viajan por HTTP entre la pantalla y el servidor.
- **events/:** Esquemas de los eventos que se envían por WebSocket y MQTT.
- **examples/:** Ejemplos de mensajes JSON (comandos y resultados).

## Regla importante

No se deben mantener contratos duplicados y divergentes en distintos lenguajes. Aquí está la versión autorizada.
