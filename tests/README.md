# tests — Pruebas del sistema

Esta carpeta contiene pruebas para verificar que todo funciona.

## Qué incluye

- **integration/:** Pruebas de que las partes se comunican bien entre sí.
- **contract/:** Pruebas de que los mensajes respetan los contratos definidos.
- **simulation/:** Pruebas sin hardware real (simulando sensores y motores).

## Objetivo

Poder probar la lógica sin necesidad del tablero físico.
